# WhoAmI

HTML/CSS/JavaScript 학습을 겸한 개인 포트폴리오 페이지입니다.
단순 자기소개를 넘어, 페이지 자체가 하나의 학습 결과물이 되도록 만들었습니다.

## 🔗 페이지 보기

[▶ pyrite9.github.io/WhoAmI](https://pyrite9.github.io/WhoAmI/)

## 📌 목적

- HTML/CSS 기본 구조 및 시맨틱 마크업 학습
- CSS 애니메이션 및 트랜지션 연습
- JavaScript DOM 조작 및 모션 구현
- Canvas API를 활용한 파티클 효과 학습
- 포트폴리오 페이지로서의 정보 구조 설계

## 🛠 사용 기술

- **HTML5** — 시맨틱 태그, Canvas
- **CSS3** — Flexbox, Grid, Keyframes, Transition, Media Query
- **Vanilla JavaScript** — DOM, Intersection Observer, requestAnimationFrame

## 📄 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| Hero | 이름 타이핑 효과 + 부제 페이드인 |
| About | 전공 및 진로 방향 |
| Skills | Languages / Infrastructure |
| Projects | 주요 프로젝트 4건 (소프트웨어 + 실무 경험) |
| Experience | 함정 IT 인프라 운용 경력 상세 |
| Certifications | 보유 자격증 |
| Footer | 연락처 |
